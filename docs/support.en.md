# Support and partnership { #support-und-partnerschaft }

Kontext is free (AGPL). If you'd rather not set it up or run it yourself, the developers help.

## Setup and migration { #einrichtung-und-umzug }

We set up Kontext and Stalwart on your server, with DNS, backups and telephony. Mails, contacts
and appointments move with you, also from Microsoft 365, Gmail, Outlook (PST) and IMAP
mailboxes.

## Support { #support }

Help with updates, backups and questions while it runs, so the server stays up to date and
reachable.

## Hosted operation { #betrieb }

Kontext as a hosted service, without a server of your own: others take care of setup, updates and
backups, your company just uses the app.

## Partnership for IT service providers { #partnerschaft-fur-it-dienstleister }

For IT service providers who set up Kontext for their customers: a direct line to the developers,
for their customers' questions, bugs and wishes.
