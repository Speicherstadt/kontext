# Mitwirken

Issues und Pull Requests sind willkommen. Fehler und Ideen über die Formulare:
[Fehler](https://github.com/Speicherstadt/kontext/issues/new?template=bug_report.yml) oder
[Wunsch](https://github.com/Speicherstadt/kontext/issues/new?template=feature_request.yml). Ein guter Fehlerbericht
nennt Browser oder Handy, die Ansicht, was passiert ist, und die Version von Kontext (*Einstellungen → Darstellung →
App auf diesem Gerät*); ein Screenshot hilft. Sicherheitsprobleme gehen vertraulich, siehe [SECURITY.md](SECURITY.md).

Wie ein Beitrag entsteht (Aufgabe übernehmen, Branch, Titel, Prüfungen, Review), steht unter
[Mitwirken](https://kontext.email/mitwirken.html); die Einrichtung unter
[Entwicklung](https://kontext.email/development.html). Agenten lesen zuerst [AGENTS.md](AGENTS.md).
